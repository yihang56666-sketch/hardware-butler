# Verification Gates

Gate 1–5 是必需门控；Gate 6 是用户请求模块原理图时才适用的可选门控。逐项记录证据、评审人、日期、状态及未关闭问题，不能仅因 `tests/validate.py` 静态检查通过就标为 PASS。未通过的方案只能标为待核草案，不能宣称可制板或已验证。

## Gate 1：需求冻结后

- [ ] 约束表中无空白必填项（场景、供电、通信、环境、成本、认证）。
- [ ] 已向用户提供 2-4 个结构化决策选项，覆盖成本、功耗、交付周期或供应链取向。
- [ ] 每个"待确认"项标注了负责人和截止时间。
- [ ] 所有"待确认"项已逐一向用户确认（用户可选择提供值、授权假设推进、或标注阻塞）。
- [ ] 用户已确认需求表，或明确授权基于假设推进。

## Gate 2：架构选择后

- [ ] 至少比较了三个候选架构：国产优先、海外主流、混合折中（除非用户指定平台或排除某类）。
- [ ] 每个候选方案有明确的优缺点和适用条件。
- [ ] 每个候选方案覆盖主控、电源、通信接口、传感器/模拟前端的器件范围。
- [ ] 推荐方案的选择理由不是"常用"或"熟悉"，而是基于约束匹配。
- [ ] 用户已确认架构方向。
- [ ] 用户确认架构方向后才能进入选型阶段，不能默认推进。

## Gate 3：选型完成后

- [ ] 关键器件（MCU、PMIC、无线、连接器）均有替代方案。
- [ ] 每个关键模块至少比较了国内候选和海外候选，或说明其中一类不适用的原因。
- [ ] 涉及国产替代或中国市场量产时，已参考 `domestic-sources.md` 覆盖国内主流芯片、元器件、模组和方案平台。
- [ ] Datasheet 来源符合统一顺序：原厂官网 > 授权分销商 > 元器件平台 > 聚合站；聚合站仅作线索，已交叉验证型号、封装、版本及证据定位页码。
- [ ] 如果参考了方案拆解或参考设计平台，已明确可借鉴点、不可直接复用点，并回溯到原厂资料验证。
- [ ] 供应链风险已联网查证：生命周期、库存、交期、认证。
- [ ] 风险表非空，且高风险项有验证动作和截止点。
- [ ] 器件参数来自数据手册或分销商页面，非记忆。
- [ ] 每个推荐的关键 IC 和功能模块器件附带采购参考链接（国内电商平台/分销商页面），或标注"需联网查证"。
- [ ] 每个推荐的关键 IC 和功能模块器件附带 datasheet 下载链接和封装文件下载链接，或标注"需联网查证"。
- [ ] 通用被动元件可不逐一下载，但影响安全或性能的额定值有证据；无证据参数只标待核，关键阻塞未关闭时 Gate 3 不能通过。

## Gate 4：方案输出后

- [ ] 输出包含系统框图、接口矩阵、电源树、PCB 约束、验证计划。
- [ ] 风险清单非空，每个风险有影响、概率、验证动作。
- [ ] 无占位符文本（"待补充""TBD""xxx"）出现在已确定项中。
- [ ] 已确定/待确认/高风险三类事项在末尾明确分列。

## Gate 5：评审完成后

- [ ] 使用 `hardware-reviewer` 或人工完成五维独立评审；不支持 agent 时的自检必须标"非独立自检，待人工复核"，未经独立复核不得标 Gate 5 PASS。
- [ ] FAIL 项已关闭；CONCERN 项已处理，或记录责任人、验证动作、截止点并经复核接受。不能仅改成"待确认"就宣称通过。
- [ ] 最终方案可直接交给硬件工程师开始原理图设计。

## Gate 6：模块原理图输出后（可选）

用户未请求模块原理图时记录不适用及原因；不要求为了完成模板而生成器件连接或未经核实的参数。

- [ ] 已询问用户是否需要模块原理图，用户确认需要后才输出。
- [ ] 用户已选择展示方式（结构化连接表 / ASCII 框图 / D2 图表 / KiCad 原理图文件 / 立创 EDA JSON）。
- [ ] 若用户选择 KiCad 或立创 EDA 格式，已确认对应 MCP Server 可用；不可用时已提示用户并回退到结构化连接表。
- [ ] 已按用户指定的模块范围和展示方式输出原理图片段。
- [ ] 每个模块标注了器件型号、引脚连接和关键参数值。
- [ ] 电源轨标注了电压和电流预算。
- [ ] 原理图片段可直接交给硬件工程师用于 EDA 绘制。
