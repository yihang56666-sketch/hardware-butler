# Download Sources Registry

这是只读登记模板，不是已验证来源数据库。实际记录写入用户项目的 `docs/hardware/download-sources.md`，不要修改已安装的共享技能。不存在记录时不能宣称某站点已验证可用；同系列器件也不能自动复用参数结论。

## 使用规则

1. 查阅项目登记，遵循原厂官网 > 授权分销商 > 元器件平台 > 聚合站；聚合站只作候选线索
2. 在项目登记中记录下载结果与参数核验结果，两者不能混为一谈
3. 记录原厂版本、精确型号/封装、页码和文件 SHA-256；无法核实只标待核
4. 来源失效时记录实际日期与原因；不得绕过登录、验证码或访问控制
