## 这是什么

这是一个基于 STM32 的小型四旋翼无人机硬件方案包，目标是先做出能实验、能调、能悬停的原型机。

## 当前结论

- 主控推荐 STM32G431
- 姿态传感推荐 SPI IMU
- 第一版用外置 4-in-1 ESC
- 第一版不做自研电调
